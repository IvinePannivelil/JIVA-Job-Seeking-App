# JIVA – Job Seeking Application

JIVA is a Flutter-based job-seeking application designed to simplify the process of discovering job opportunities and managing job applications through a user-friendly mobile interface.

## 📱 Overview

The application provides job seekers with features for:

- User authentication
- Browsing recent job opportunities
- Viewing detailed job information
- Managing application details
- Viewing submitted application information
- Job-seeking tips and guidance
- Local user-data management

## 🚀 Features

### 🔐 Authentication
- Login screen with credential validation
- Password visibility toggle
- Persistent user preferences

### 💼 Job Discovery
- Recent job listings
- Company information
- Job title and location
- Salary and job type
- Job requirements and descriptions
- Detailed job views

### 📄 Application Management
- View application details
- Store and retrieve application information
- Manage user-specific application data

### 🎨 User Interface
- Splash screen
- Custom application theme
- Reusable UI components
- Job-seeking tips
- Intuitive navigation

## 🛠️ Tech Stack

- **Flutter**
- **Dart**
- **SharedPreferences**
- Flutter Material UI
- Named route navigation
